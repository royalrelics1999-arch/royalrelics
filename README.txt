VAYRO LUXURY EYEWEAR — CUSTOMISABLE FRONT-END STARTER

FILES
- index.html: website structure and editable page content
- style.css: all styles, layout, responsive rules and brand colours
- script.js: product cards, category filter, search and demo cart

HOW TO RUN
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.

HOW TO CUSTOMISE
1. Brand name: replace VAYRO in index.html.
2. Brand colours: edit --accent, --ink and --paper at the top of style.css.
3. Fonts: change the Google Fonts link in index.html and --font-body / --font-display in style.css.
4. Hero/category photos: replace the image URLs in style.css.
5. Products: edit the PRODUCTS array near the top of script.js. Each product has id, name, type, price, tag and image.
6. Contact email and social links: update footer links in index.html.

IMPORTANT
This is a front-end demo. The cart works in the browser but does not save orders, process payments, manage inventory, or send newsletter emails. Those need a backend and secure payment/email integrations before going live. Product images are remote sample images; replace them with photos you own or are licensed to use.
